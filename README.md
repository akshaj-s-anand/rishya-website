# Rishya Beauty Lounge website (PHP branch)

This is the deployable PHP version. The `main` branch holds the static HTML preview.

## Run locally
```
cd site-php
php -S localhost:8000
```
Open http://localhost:8000

## Gemini chat ("Ask Rishya")
1. Copy `includes/config.local.example.php` to `includes/config.local.php`.
2. Paste your Google AI Studio API key into it. The file is git-ignored.
3. The chat widget posts to `api/ask.php`, which answers only from `includes/knowledge.txt`.

## Editing content
Pages are generated by `build.py` (in the parent folder):
`python build.py site site-php`
